# Заявки з лендінгу в Telegram

Форма замовлення надсилає дані на невеликий сервер (Cloudflare Worker, безкоштовно), а він пересилає їх вашому боту в Telegram.
Токен бота зберігається на сервері, а не в коді сайту, тож ніхто сторонній не зможе ним скористатися.

## 1. Створіть бота
1. У Telegram відкрийте **@BotFather** → `/newbot`.
2. Вкажіть назву та імʼя бота (має закінчуватися на `bot`).
3. Скопіюйте **токен** — рядок виду `1234567890:AA...`.

## 2. Дізнайтеся chat_id
1. Напишіть своєму боту будь-яке повідомлення (або додайте бота в групу менеджерів і напишіть там).
2. Відкрийте в браузері `https://api.telegram.org/bot<ТОКЕН>/getUpdates`.
3. Знайдіть `"chat":{"id": ...}` — це **CHAT_ID** (для групи він від'ємний, з мінусом).

## 3. Запустіть Worker
1. Зареєструйтеся на [dash.cloudflare.com](https://dash.cloudflare.com).
2. **Workers & Pages → Create → Create Worker**, назвіть, наприклад, `sonline-orders`, натисніть **Deploy**.
3. **Edit code** → видаліть усе й вставте вміст `telegram-order.js` → **Deploy**.
4. **Settings → Variables and Secrets** → додайте:
   - `BOT_TOKEN` — токен бота (тип **Secret**);
   - `CHAT_ID` — chat_id;
   - `ALLOWED_ORIGIN` — адреса вашого сайту, напр. `https://sonline.com.ua` (без `/` у кінці). Можна додати пізніше, коли буде домен; поки змінної немає, приймаються запити з будь-якого сайту.
5. Скопіюйте адресу воркера — `https://sonline-orders.<ваш-акаунт>.workers.dev`.

## 4. Підключіть сайт
У `script.js` вставте адресу:
```js
const ORDER_ENDPOINT = "https://sonline-orders.<ваш-акаунт>.workers.dev";
```
Зробіть тестове замовлення — повідомлення має прийти в Telegram.

## Як виглядає повідомлення
```
🛏 Нове замовлення

Матрац «Азалія», 180×200 см × 1 шт.
Сума: 19 000 ₴

👤 Іван
📞 067 123 45 67
💬 після 18:00
```
Для «Іншого розміру» заголовок буде «🛠 Заявка на розмір під замовлення» і «Сума: ціна за запитом».
