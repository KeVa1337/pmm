# Google Реклама для лендінгу «Камелія»

Сайт уже готовий до реклами: конверсії, джерело заявки, політика конфіденційності, розділ «Доставка й оплата», мікророзмітка товару, фід для Google Merchant.
Залишилось створити акаунти й вписати ідентифікатори в `script.js`.

---

## 1. Підключити відстеження (обовʼязково до запуску)

### Google Analytics 4
1. [analytics.google.com](https://analytics.google.com) → Адміністрування → **Створити ресурс** → веб-потік для `https://sonline.lumex-ua.com`.
2. Скопіюйте **ідентифікатор показника** `G-XXXXXXXXXX`.

### Конверсія в Google Ads
1. [ads.google.com](https://ads.google.com) → **Цілі → Конверсії → Нова дія-конверсія → Вебсайт** → «Додати дію вручну».
2. Налаштування:
   - Категорія: **Надіслання форми потенційного клієнта** (Submit lead form);
   - Назва: `Замовлення матраца`;
   - Цінність: **Використовувати різну цінність для кожної конверсії** (сайт передає суму замовлення), запасна — 21990 UAH;
   - Кількість: **Одна**;
   - Увімкніть **Розширені конверсії** (Enhanced conversions) → спосіб «Google tag».
3. Оберіть «Налаштувати самостійно за допомогою Google tag» і скопіюйте з коду два значення:
   `send_to: 'AW-1234567890/AbCdEfGh'` → `AW-1234567890` — це **adsId**, `AbCdEfGh` — **adsLeadLabel**.
4. (Необовʼязково) друга конверсія `Дзвінок / Telegram` — категорія «Контакт», цінність без значення, тип «Вторинна». Її мітка — **adsContactLabel**.

### Вписати ID на сайт
У `script.js` на початку:
```js
const GOOGLE = {
  ga4Id: "G-XXXXXXXXXX",
  adsId: "AW-1234567890",
  adsLeadLabel: "AbCdEfGh",
  adsContactLabel: "",
};
```
Змініть `?v=...` в `index.html`, перезберіть архів і залийте на хостинг.

### Що відстежується
| Подія | Коли | Куди |
|---|---|---|
| `begin_checkout` | відкрили форму замовлення | GA4 |
| `generate_lead` + конверсія Ads | замовлення успішно надіслане (з сумою) | GA4 + Ads |
| `contact` (+ конверсія Ads, якщо є мітка) | клік по телефону чи Telegram | GA4 + Ads |

Телефон покупця передається в Google для розширених конверсій (gtag сам хешує його).

### Джерело заявки в Telegram
Якщо покупець прийшов з реклами, в повідомленні буде рядок:
```
📈 Джерело: google / cpc / camelia (gclid)
```
Для цього в Google Ads увімкніть **автоматичне додавання тегів** (Налаштування акаунта → Auto-tagging) і додайте шаблон відстеження (Налаштування акаунта → Шаблон кінцевої URL-адреси):
```
{lpurl}?utm_source=google&utm_medium=cpc&utm_campaign={_campaign}&utm_term={keyword}
```
і користувацький параметр `_campaign` у кожній кампанії (наприклад, `camelia_search`).

> Після оновлення сайту також оновіть код воркера в Cloudflare з `worker/telegram-order.js` — інакше рядка «Джерело» не буде.

## 2. Пошукова кампанія (з неї починати)

**Тип:** Пошук. Мережі: лише пошук Google (вимкніть контекстно-медійну мережу і пошукових партнерів на старті).
**Місцезнаходження:** Україна, «Присутність: люди, які перебувають у вибраних місцях».
**Мови:** українська, російська.
**Розклад:** цілодобово; через 2 тижні подивіться звіт і знизьте ставки вночі, якщо заявок немає.
**Стратегія:** перші 1–2 тижні — **Максимум кліків** з обмеженням ставки ~25 ₴, після 15–20 конверсій — **Максимум конверсій**, після 30+ — **Цільова ціна за конверсію**.
**Бюджет на старті:** 500–800 ₴/день.

### Скільки можна платити за заявку
Маржа ≈ 11 500–12 400 ₴ з матраца. Якщо з 10 заявок викуповують 6–7, прийнятна ціна заявки — до **2 000–3 000 ₴**. Почніть з цільової ціни ~1 500 ₴ і коригуйте за фактом.

## 3. Google Merchant Center + Товарні оголошення (другий етап)
Для матраців товарні оголошення з фото й ціною часто працюють найкраще.

1. [merchants.google.com](https://merchants.google.com) → додайте сайт `sonline.lumex-ua.com`, підтвердьте право власності (через тег Google або HTML-файл у `public_html`).
2. **Товари → Додати товари → Файл → За розкладом** → URL `https://sonline.lumex-ua.com/feed.xml`, щодня.
3. Заповніть **Доставку** (Україна, Нова пошта, 1–3 дні, вартість — за тарифами перевізника) і **Правила повернення** (14 днів, за Законом «Про захист прав споживачів»).
4. Звʼяжіть Merchant Center з Google Ads і створіть кампанію **Performance Max** або **Торгову** з бюджетом 300–500 ₴/день.

> Якщо змінюєте ціни на сайті — змініть їх і у `feed.xml`, інакше Google відхилить товари через невідповідність ціни.

## 4. Перед запуском — чек-лист
- [ ] ID Google вписані в `script.js`, сайт оновлено, кеш Hostinger очищено.
- [ ] Тестове замовлення: прийшло в Telegram, в Google Ads у статусі конверсії зʼявилось «Записується конверсії» (до 24 год).
- [ ] Воркер у Cloudflare оновлено, вибір відділень Нової пошти працює.
- [ ] `ALLOWED_ORIGIN` = `https://sonline.lumex-ua.com` у воркері.
- [ ] У політиці конфіденційності вказано ваше ФОП / юрособу (рекомендовано Google).
- [ ] Ціна виробника (закреслена) актуальна — Google може відхилити оголошення, якщо порівняння цін неправдиве.
- [ ] Менеджер готовий передзвонювати протягом 15 хв — швидкий дзвінок сильно підвищує викуп.

## 5. Після запуску
- **Щодня перші 3 дні:** пошукові запити → мінус-слова.
- **Щотижня:** вартість заявки, % викупу, які групи дають продажі — бюджет туди.
- **Через 2–4 тижні:** перехід на «Максимум конверсій», запуск ремаркетингу (аудиторія «Відвідувачі сайту, які не залишили заявку», 30 днів).
