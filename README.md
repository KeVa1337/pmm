# Лендінг матраца «Азалія»

Статичний односторінковий сайт: `index.html`, `styles.css`, `script.js`. Збірка не потрібна — відкрийте `index.html` у браузері або залийте файли на будь-який хостинг.

## Що є
- Опис моделі: переваги, будова та матеріали, сторони зима-літо, характеристики, FAQ.
- Фото товару: інтерʼєр, будова в розрізі, пружинний блок (`assets/azalia-*.webp`).
- Вибір розміру: 140×200 (7 900 ₴), 160×200 (8 865 ₴), 180×200 (10 017 ₴), висота 22 см. Ціна та превʼю оновлюються одразу.
- Таблиця розмірів і цін (клік по рядку обирає розмір).
- Форма замовлення з перевіркою імені й телефону.

## Налаштування (`script.js`)
- `PRODUCT` — назва та висота.
- `SIZES` — розміри та ціни.
- `ORDER_ENDPOINT` — URL, куди POST-ом надсилається замовлення у JSON. Поки порожній, замовлення лише показує підтвердження.

Назва магазину SonLine і телефон `+38 (000) 000-00-00` — заглушки, замініть на свої.
