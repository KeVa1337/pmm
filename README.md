# SonLine — лендінг ортопедичних матраців

Статичний односторінковий сайт: `index.html`, `styles.css`, `script.js`. Збірка не потрібна — відкрийте `index.html` у браузері або залийте файли на будь-який хостинг.

## Що є
- Конфігуратор: модель (Comfort / Ortho Pro / Premium Memory), ширина 70–200 см, довжина 190/200 см, нестандартний розмір (+20%), кількість. Ціна та превʼю оновлюються одразу.
- Таблиця всіх розмірів і цін (клік по рядку обирає розмір).
- Форма замовлення з перевіркою імені й телефону.

## Налаштування (`script.js`)
- `MODELS` — назви, висота, жорсткість, ціна за м².
- `SIZES` — список стандартних розмірів.
- `DISCOUNT`, `CUSTOM_MARKUP` — знижка та націнка на нестандарт.
- `ORDER_ENDPOINT` — URL, куди POST-ом надсилається замовлення у JSON. Поки порожній, замовлення лише показує підтвердження.

Телефон `+38 (000) 000-00-00` і відгуки — заглушки, замініть на свої.
